
# Scalable Big Data Analytics for Crop Yield Prediction

## Project Overview

This project predicts agricultural crop yield in India
using multi-source agricultural and weather data.

## Datasets

1. India Crop Yield Prediction Dataset
   Source: Hugging Face

2. State-wise Weather Dataset
   Source: Public GitHub repository

## Technologies

- Python
- Google Colab
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Flask
- HTML
- CSS
- Machine Learning

## Machine Learning Models

1. Linear Regression
2. Decision Tree Regressor
3. Random Forest Regressor
4. Gradient Boosting Regressor
5. Extra Trees Regressor

## Evaluation Metrics

- MAE
- MSE
- RMSE
- R2 Score

## Target

Crop Yield (metric tonnes per hectare)

## Run Locally

Install dependencies:

pip install -r requirements.txt

Start the Flask application:

python app.py

Open:

http://127.0.0.1:5000/

## Important

The model is trained using historical records
and should be treated as an educational prediction
system, not an official agricultural forecast.
